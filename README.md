# Never Ending Captures — Interiors & Corporate Portfolio

A responsive static portfolio for interior/architecture photography, property films, corporate event photography and corporate videography.

## Features
- Full-screen interior walkthrough video hero with a still-image poster fallback
- Responsive desktop, tablet and mobile layouts
- Interior and architecture photo gallery using original portfolio images and enhanced frames from the supplied video
- Dedicated corporate event photography and film service section
- Interior film playback modal
- Mobile navigation, accessible controls and reduced-motion handling
- WhatsApp, email, phone and Instagram enquiry links
- No framework, build step, database or required third-party form service
- GitHub Pages and Netlify compatible

## Contact settings
Update `assets/js/config.js` to change the WhatsApp number, enquiry message, email, Instagram URL or location.

## GitHub Pages deployment
1. Extract this ZIP file.
2. Open the `never-ending-captures-portfolio` folder.
3. Upload the contents of that folder to the root of your existing GitHub repository, replacing the old files.
4. Keep the existing repository, GitHub Pages branch/folder settings and custom-domain settings unchanged.
5. Wait for GitHub Pages to publish the update, then refresh the same website URL.

## Video performance
The supplied 4K video has been converted into a lightweight 720p, 24fps, 12-second loop for the hero and film preview. This is intentionally optimized for faster loading on mobile connections. Keep the original 4K master separately for future edits.

## Image notes
Ten original still frames were extracted directly from different timestamps in the supplied 4K interior walkthrough at high resolution. They were lightly enhanced for exposure, contrast, colour and sharpness without replacing or generating any scene content. The frames are displayed in a dedicated 10-image interior gallery. Existing interior portfolio photographs and the supplied updated logo has been integrated.
